# Civolution

Civilization III Complete (Conquests rules) rebuilt as a single-player TypeScript web app with a modern 3D map, a polished UI and first-class player automation.

The plan lives in [docs/PLAN.md](docs/PLAN.md); rule notes in [docs/rules](docs/rules/README.md).

## Setup

Requires Node 24 and pnpm 11.

```bash
pnpm install
pnpm check          # typecheck, lint, tests
pnpm dev            # the game at http://localhost:5173
pnpm sim -- --size huge --turns 100   # a headless game, JSON report
```

The map benchmark runs at `http://localhost:5173/?bench`; the UI smoke test with
`pnpm --filter @civolution/client e2e`. See [docs/rendering.md](docs/rendering.md) and
[docs/assets.md](docs/assets.md).

## Importing the original rules

The game's rule numbers are read from your own Civ3 Complete install. Copy `.env.example`
to `.env` and point `CIV3_PATH` at the install, then:

```bash
pnpm run import
```

This writes `data/imported/*.json`, which is gitignored: original game files and their
contents are never committed. See [docs/rules/importing.md](docs/rules/importing.md).

## Packages

| Package | Purpose |
|---|---|
| `packages/importer` | BIQ/BIX/BIC decompressor and parser, Civilopedia and text parsers, `pnpm run import` |
| `packages/data-schema` | Zod schemas and types for the imported data and our curated rule set |
| `packages/rules` | Our curated Conquests rule set (`data/conquests.json`), regenerated by `pnpm rules:curate` |
| `packages/engine` | Deterministic game core: state, map generator, movement, fog, workers, turns, saves, invariants |
| `packages/automation` | Player automation routines (explore, auto worker) issuing ordinary commands with reasons |
| `packages/sim` | Headless games: scripted players, invariant checks, replays, `pnpm sim` |
| `packages/client` | React + three.js game client, engine in a Web Worker, local saves |
| `packages/assets` | OpenRouter art pipeline and manifests |
